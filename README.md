## About

**SoundFean** is a backend-powered music addon service designed to provide music-source integrations to compatible applications.

Rather than being an addon platform inside its own player, SoundFean makes integrations available through its backend so supported apps can connect to configured music sources.

## What it offers

* **Music-source integrations** — backend services for supported music sources.
* **App connectivity** — provides addon functionality to compatible applications.
* **Centralized backend** — integrations are managed through the SoundFean service.
* **Quality-aware playback support** — audio quality and formats depend on the source and integration.
* **Evolving integrations** — the backend can be extended as support for additional sources develops.
